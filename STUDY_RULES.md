# Study Rules and Learning Methodology

## 1. General Principles

- Consistency over speed.
- Understanding over memorization.
- Practice over passive learning.
- Independent problem-solving.
- Regular revision.
- Building real applications.

## 2. Language

- Lessons and explanations: Russian.
- Technical terminology: English.
- Code comments and documentation: English where practical.
- Technical documentation: English whenever possible.

## 3. Lesson Structure

Each lesson should contain:

1. Learning objectives.
2. Theoretical explanation.
3. Code examples.
4. Practical exercises.
5. Independent assignments.
6. Review and feedback.
7. Summary of key concepts.

## 4. Practical Learning

- Write code independently.
- Avoid copying solutions without understanding.
- Explain important programming decisions.
- Learn to read error messages.
- Practice debugging.
- Use Git regularly.
- Document completed projects.

## 5. Assessment

Knowledge should be evaluated through:

- Practical assignments.
- Code reviews.
- Small projects.
- Knowledge tests.
- Independent implementation.
- Technical explanations.

## 6. Revision

Previously studied subjects should be reviewed regularly.

Difficult topics should receive additional practice before moving forward.

## 7. Learning Schedule

Initial target:

- 3–4 focused hours per day.
- 5–6 study days per week.
- Regular breaks.
- At least one flexible rest day.

The schedule can be adjusted according to health, concentration and learning progress.

## 8. Main Learning Rule

Never confuse completing a lesson with mastering a subject.

The objective is to develop practical skills that can be used in professional software development.
